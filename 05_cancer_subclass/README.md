# 유전자 변이 정보 기반 암종 분류

제1회 디지털 바이오 데이터 분석 경진대회 · **은상**

## 문제

환자별로 **4,384개 유전자의 변이 정보**가 `R123R`, `A123R`, `G12fs`, `Q61*` 같은 문자열로 주어진다.
이 정보만으로 환자의 암종(`SUBCLASS`)을 다중 분류한다.
변이 문자열은 그대로는 모델에 넣을 수 없고, 무엇이 의미 있는 신호인지 정해서 수치로 바꿔야 한다.

## 접근

핵심은 모델이 아니라 **변이 문자열에서 어떤 파생변수를 뽑을지 설계하는 일**이었다. 분자생물학적 의미를 기준으로 나눴다.

- **변이 종류별 개수** — 동의성 변이(`R123R`처럼 아미노산이 바뀌지 않는 변이, 정규식 `^([A-Z])\d+\1$`로 판별), 미스센스 변이, frameshift(`fs`), nonsense(`*`), in-frame indel, 총 변이 수
- **아미노산 정보** — 20종 아미노산에 대해 변이 전/후 등장 유무와 개수, 그리고 가능한 380개 변이쌍(예: `A→R`)의 존재 여부
- **변이 위치** — 유전자별 변이 위치의 최솟값·최댓값
- **암종 특이 신호** — 암종별로 동의성 변이가 가장 많이 일어난 위치 top 5, 최빈 변이 top 3, 다중 변이 상위 위치를 찾아 해당 위치의 변이 유무를 파생변수로
- **도메인 지식 주입** — 대표적인 **oncogene 34종**(EGFR, BRAF, PIK3CA, MYC …)과 **tumor suppressor gene 24종**(TP53, RB1, BRCA1/2, PTEN …)의 변이 여부를 별도 변수로
- **군집 라벨을 피처로** — 변이 개수 기반 / 아미노산 기반 / 상위 변이 위치 기반의 세 가지 KMeans를 돌려 클러스터 라벨을 추가했다. `k`는 엘보우 방법과 실루엣 점수를 함께 보고 정했다.
- 동의성 변이는 아미노산을 바꾸지 않으므로, 개수를 센 뒤에는 `WT`로 치환해 잡음을 줄였다.

분류기는 `XGBClassifier`(`n_estimators=100`, `learning_rate=0.1`, `max_depth=6`, `eval_metric='mlogloss'`)를 사용했다.

## 결과

**은상** 수상.
