# K리그 경기 이벤트 다음 위치 예측

DACON × 서울시립대 공개 AI 경진대회 · Track 1 알고리즘 부문 · **9위 / 937팀**

## 문제

축구 경기의 이벤트 시퀀스(패스·슈팅 등의 종류, 결과, 팀, 홈/원정, 경과 시간)가 주어졌을 때
다음 이벤트가 발생할 필드 좌표 `(x, y)`를 예측한다.
한 경기가 여러 에피소드로 나뉘고, 에피소드마다 이벤트 길이가 달라 가변 길이 시퀀스를 다뤄야 한다.

## 접근

- 이벤트를 `type / result / team / home` 임베딩 + 수치형 14개로 인코딩하고, 최대 길이 21로 패딩한 뒤 **Hybrid Context GRU**로 시퀀스를 요약했다. 활성화는 GELU, 출력단에 Multi-Sample Dropout을 적용했다.
- 경기 맥락을 반영하기 위해 **KMeans로 11개 클러스터를 만들어 클러스터 임베딩(4차원)** 을 컨텍스트로 함께 넣었다.
- **5-Fold × 손실 가중치 3종**(`base` 1:1, `x_focus` 2:1, `y_focus` 1:2)으로 15개 모델을 학습해 MoE 방식으로 앙상블하고, 장거리 이동 예측에 감쇠 보정을 적용했다.

## 결과

최종 **9위 / 937팀**. 제출 점수 12.562 (파일명이 곧 점수).
