# 무역 품목 간 선행–후행 관계 탐지와 수요 예측

제3회 국민대학교 AI빅데이터 분석 경진대회 · **40위 / 960팀**

## 문제

품목별 월간 무역량이 주어졌을 때, 어떤 품목의 움직임이 다른 품목의 움직임을 **먼저 예고하는지**(선행–후행 쌍)를 찾고,
찾아낸 선행 품목의 과거 값으로 후행 품목의 다음 달 무역량을 예측한다.
품목 수가 많아 쌍의 조합이 크고, 값이 0인 구간이 많아 상관계수가 쉽게 왜곡된다.

## 접근

- `item_id × 연월` 피벗으로 월별 무역량 행렬을 만들고, 모든 품목쌍에 대해 **lag 1~12개월**을 적용해 상관을 계산했다.
- 우연한 상관을 걸러내기 위해 세 겹의 조건을 뒀다. **① Pearson과 Spearman의 부호 일치** 검사, **② lag 구간별 동적 임계값**(lag ≤ 6이면 0.35, 그 이상은 0.40), **③ 12개월 롤링 윈도우**에서 상관이 지속되는지 확인.
- 유효 구간이 짧거나(9개월 미만) 0의 비율이 절반을 넘는 쌍은 계산에서 제외했다.
- 선정된 쌍에 대해 `(후행_t, 후행_{t-1}, 선행_{t-lag})`을 설명변수로 선형회귀를 적합해 다음 달 값을 예측했다.

## 결과

최고 점수 **0.3837**, 최종 **40위 / 960팀**.

## 노트북 읽는 법

`선후행 무역데이터.ipynb` 는 실험 과정을 그대로 남긴 노트북이다. 임계값·lag 범위·로그 변환 여부를 바꿔가며
같은 함수를 여러 번 재작성했고, **각 셀 첫 줄 주석에 그 설정의 점수가 적혀 있다.**

| 설정 | 점수 |
|---|---|
| **부호 검사 + 롤링 지속성 + 동적 임계값 (0.35 / 0.40)** | **0.3837 ← 최고** |
| 롤링 기법 적용 | 0.382 |
| Spearman 부호 검사 추가 | 0.3794 |
| 임계값 전 구간 0.35 | 0.376 |
| 기본 lag 상관 | 0.3717 |
| lag를 18까지 확장 | 0.356 |
| 임계값 0.3 / 0.35 | 0.354 |

최고 성능 셀은 `# 이게 진짜 최고 코드 0.3837` 주석이 붙은 셀이다.
lag를 18개월까지 늘리면 오히려 점수가 떨어졌는데, 표본 구간이 짧아져 상관이 불안정해지기 때문이다.
