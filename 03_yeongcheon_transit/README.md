# 영천시 버스정류장 설치 후보지역 분석

영천시 빅데이터 분석 공모전 · 공공데이터 기반 공간 분석

## 문제

영천시에서 대중교통 접근성이 떨어지는 지역을 찾고, 버스정류장을 새로 놓는다면 어디가 우선인지 근거를 제시한다.
행정동 단위로는 내부 편차가 묻히기 때문에 더 작은 공간 단위로 볼 필요가 있었다.

## 접근

- 행정동이 아닌 **격자(grid) 단위**로 인구·이동 데이터를 결합해 지역 내부의 편차가 드러나도록 했다.
- 격자별 수요(인구·이동량)와 기존 정류장까지의 접근성을 함께 보고 **교통취약지역**을 정의했다.
- 취약도가 높은 격자를 후보지로 뽑아 우선순위를 매겼다.
